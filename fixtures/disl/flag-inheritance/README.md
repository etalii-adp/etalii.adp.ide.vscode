# Inherited relation flags

DISL 0.6's example of relation flags inherited along the supertypes, the definition of that tool type with the findings it gives, and the three specifications a host must refuse (etalii.adp spec [034-disl-relation-flag-inheritance](https://github.com/etalii-adp/etalii.adp/tree/develop/specs/034-disl-relation-flag-inheritance), DISL section 4.7). The files are copied unchanged, byte for byte, from [etalii-adp/etalii.adp](https://github.com/etalii-adp/etalii.adp) at commit `4aa0522b195d5d0ee3139f8dc54f741a5bbb858b`, licensed under the [Apache License 2.0](https://github.com/etalii-adp/etalii.adp/blob/develop/LICENSE) as this repository is. Refresh them with `node scripts/sync-examples.mjs`, as [examples/PROVENANCE.md](../../../examples/PROVENANCE.md) says; do not edit them by hand.
