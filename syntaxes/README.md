# Syntaxes

`atd.tmLanguage.json` is the TextMate grammar of ATD, the ADP tool language, copied unchanged from etalii.adp's [`specifications/atd/highlighting/atd.tmLanguage.json`](https://github.com/etalii-adp/etalii.adp/blob/develop/specifications/atd/highlighting/atd.tmLanguage.json) at commit `d9e4905` (etalii.adp#474, which gives triple-quoted strings their lines). etalii.adp generates it from the grammar with `atd-grammar.py --highlighting`; a correction goes there and arrives here as a newer copy (etalii.adp spec 035, T112).
